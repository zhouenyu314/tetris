# 俄罗斯方块 · Tetris

一个纯前端实现的经典俄罗斯方块游戏，无需任何依赖，单文件即可运行。

**在线试玩（GitHub Pages）**：https://zhouenyu314.github.io/tetris/

## 特性

- 🎮 完整玩法：7 种方块、Bag-7 随机、幽灵方块（落点预览）
- 🔄 SRS 风格踢墙旋转（Wall Kick）
- 📦 Hold 暂存 + Next 三连预览
- ⚡ 软降 / 硬降 / 连击加分、等级随消行提升
- 📱 移动端适配：触控按钮 + 自适应布局
- 🏆 最高分本地保存（localStorage）
- 🎨 深色霓虹风格 UI、消行闪光与屏幕震动效果

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 软降（加速下落） |
| ↑ / X | 顺时针旋转 |
| Z / Shift | 逆时针旋转 |
| 空格 | 硬降（瞬间落底） |
| C / 右Shift | 暂存方块（Hold） |
| P / Esc | 暂停 |
| R | 重新开始 |

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无需服务器。

## 技术栈

纯 HTML + CSS + JavaScript（Canvas），零依赖，单文件约 820 行。

## 部署

仓库通过 GitHub Pages 自动部署（`main` 分支根目录）。
